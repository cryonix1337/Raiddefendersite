Commandes du bot RaidDefender

Une base de commandes simple pour gerer la protection, la blacklist, les logs et la moderation anti-raid.

Protection

/antiraid enable

Active la protection anti-raid sur le serveur.

Protection

/antiraid disable

Desactive temporairement la protection anti-raid.

/antibot

/antibot

evite l'entrer des bots.

/antiban

/antiban true

evite un massif de ban.

Logs

/logs set

Definit le salon ou les actions du bot seront envoyees.

Stats

/botinfo

Affiche les statistiques du bot.

Config

/panel

Affiche la configuration actuelle de RaidDefender.

Aide

/help

Liste toutes les commandes disponibles.
